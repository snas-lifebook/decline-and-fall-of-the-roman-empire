# 가이드 그림 출처

피그마 파일 `AgGpqrga65nbd1SpAfzm91`(「인생책편데」) 페이지 **`79:2` 「옵시디언」**에서 **패널 프레임 단위로** 렌더한 뒤 WebP(폭 1200, `cwebp -q 80`)로 변환한 것이다. 31장 1.3MB.

## 왜 프레임 단위인가

각 패널의 빨간 강조 박스·①② 원문자·"지도 안 뜸" 같은 주석은 **스크린샷 이미지 위에 얹힌 별개의 벡터·텍스트 노드**다. 래스터 fill만 받으면 가이드의 핵심 정보가 통째로 날아간다. 그래서 이미지가 아니라 패널을 통째로 렌더한다.

## 다시 뽑을 때

옵시디언 UI가 바뀌면 다시 찍어야 한다. 피그마 asset URL은 7일이면 만료되므로 **node-id가 유일하게 오래 가는 참조**다.

1. 피그마에서 해당 패널을 다시 캡처해 갱신한다
2. Figma MCP `get_screenshot`에 node-id와 `maxDimension: 1200`을 준다
3. `cwebp -q 80 <in.png> -o <out.webp>`로 바꾸고 **같은 파일명으로 덮어쓴다**
4. 본문 마크다운(`site/content/start/*.md`)은 파일명을 참조하므로 고칠 필요가 없다

## 피그마 원본의 결함 (사이트로 옮길 때 손본 것)

베끼면 안 되는 자리 셋이 조사에서 나왔다. **피그마를 고치지 않고 사이트에서만 바로잡았다.**

- `79:201`과 `79:206`은 캡션이 글자 그대로 같다 — 중복 패널이라 하나만 썼다
- 라벨은 "②ZIP 파일 다운 → 5-a"인데 `5-a`는 ChatGPT 연동이고, 실제 화살표(`79:207`)는 ZIP 경로를 5-a를 건너뛰고 6번으로 보낸다 — 넘버링 오류. 사이트는 ZIP과 주소복사를 갈림길 표로 갈라 이 혼선을 없앴다
- `5-b-3`이 두 번 나오고, 「다」 섹션의 `9-1/9-2/9-3`은 제목이 셋 다 같으며 7·8번 단계는 존재하지 않는다
