인물이 추가되고 틀린 것이 고쳐집니다. 받아둔 자료를 최신으로 맞추는 방법이 셋 있는데, **하나만 고르시면 됩니다.**

## 셋 중 어느 것을 쓰시겠어요

| | ZIP 다시 받기 | Obsidian Git | 터미널 |
|---|---|---|---|
| 누구에게 | 아무것도 깔기 싫으신 분 | 옵시디언 안에서 끝내고 싶은 분 | 터미널이 익숙하신 분 |
| 준비 | 없음 | 플러그인 하나 설치 | 이미 깃으로 받아두셨어야 함 |
| 갱신할 때 | 받아서 폴더 교체 | 옵시디언을 켜면 알아서 | `git pull` 한 줄 |

**처음이시면 ZIP을 권합니다.** 대부분 이걸로 충분합니다.

## ZIP 다시 받기

[최신 자료 ZIP으로 받기](link:zip)

받은 파일의 압축을 풀고, 쓰던 폴더를 새 것으로 바꾸면 끝입니다. 가장 간단하고 아무것도 설치하지 않습니다.

폴더 안에 직접 써둔 메모가 있다면 그것만 따로 빼두었다가 옮기세요.

## Obsidian Git 플러그인

옵시디언을 켤 때마다 바뀐 것만 알아서 받아옵니다. 한 번 설정해두면 그다음부터는 신경 쓸 일이 없습니다.

커뮤니티 플러그인에서 `Obsidian Git`을 찾아 [Dataview와 같은 방식](/start/plugins)으로 설치하고 활성화하시면 됩니다.

## 터미널

이미 [깃허브](link:repo)에서 받아두셨다면 그 폴더에서 이 한 줄이면 됩니다.

```
git pull
```

## 자료가 바뀐 걸 어떻게 아나

이 사이트 아래쪽에 **데이터 기준일**이 적혀 있습니다. 그 날짜가 받아두신 것보다 나중이면 갱신할 때입니다.
