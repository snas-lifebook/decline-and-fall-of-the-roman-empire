# 일리리쿰

### 포인트별 서술

- **19. 황제가 자초한 제국의 쇠망** — 로마 제국의 북방 속주. 참주 인게누스가 황제를 사칭했던 지역이다.
- **20. 4분할 통치의 음양** — 로마 제국의 동방 속주. 갈레리우스가 방위 책임을 맡았다.

### 영토

**기원전 1세기~서기 4세기 초 (동/서 분할 이전)** — 아우구스투스가 정비한 로마의 공식 속주/관할구. 해안의 달마티아와 내륙의 판노니아를 아우르는 행정 단위로, 지역명인 일리리아보다 좁고 명확한 경계를 가진다. 참주 인게누스가 이곳에서 반란을 일으켰고, 갈레리우스가 방위를 맡았다.
