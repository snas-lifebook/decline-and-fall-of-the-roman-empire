# 샤푸르

### 포인트별 서술

- **18. 페르시아 군에게 체포당한 황제** — 사산조 페르시아의 왕. 아르메니아를 정복하고 에데사 전투에서 발레리아누스를 체포했다. 로마에 대해서는 잔혹했지만 아르메니아에서는 관대했다.
- **22. 두 번 다시 통합되지 못한 제국의 행방** — 페르시아 왕. 로마와의 전쟁에서 율리아누스를 격퇴했다.
