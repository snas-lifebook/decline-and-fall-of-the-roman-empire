# 에크노무스 해전

기원전 256년 시칠리아 섬 남해안 에크노무스 곶(현 리카타 인근)에서 벌어진 로마와 카르타고의 해전. 로마 함대 330척이 카르타고 함선 40척 이상을 격침. 책은 이 사건을 '마르살라 만'(서단)으로 잘못 서술한다.
