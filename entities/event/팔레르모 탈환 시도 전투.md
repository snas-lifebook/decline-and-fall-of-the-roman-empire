# 팔레르모 탈환 시도 전투

기원전 250년경 카르타고의 하스드루발 장군이 시칠리아 섬의 팔레르모를 탈환하려던 전투. 로마의 저항으로 카르타고군은 병사 2만 명을 잃고 대패함.
