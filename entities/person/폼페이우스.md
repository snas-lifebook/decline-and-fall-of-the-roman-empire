# 폼페이우스

### 포인트별 서술

- **5. 카이사르 등장 이전의 혼란** — 술라를 지지하는 귀족군에 가담했으며, 후에 스파르타쿠스 반란을 진압하고 로마의 실력자가 되었다. 나중에 카이사르와 삼두정치를 이루었다.
- **6. 천적과의 전쟁** — 부와 행운을 가진 카이사르의 정적으로, 카이사르의 딸 율리아와 결혼했으나 나중에 카이사르와 인연을 끊고 보수파의 수장으로 전향했다.
- **7. 로마 영웅과 이집트 여왕의 밀애** — 카이사르의 정치적 적으로 갈리아 총독 임기 연장을 반대하고 내전을 벌였으나 패배하여 이집트에서 살해되었다.
- **8. 카이사르와 원로원의 대결** — 카이사르의 정치적 적. 파르살루스에서 패배하고 이집트에서 살해되었다.
- **8. 카이사르와 원로원의 대결** — 폼페이우스의 아들. 에스파냐에서 군을 일으켰으나 패배하여 살해되었다.
- **13. 로마 제국의 정신적 통일** — 기원전 63년 오리엔트 원정 시 예루살렘을 총공격하여 점령하고 유대인의 땅을 로마의 보호령으로 만든 인물.
